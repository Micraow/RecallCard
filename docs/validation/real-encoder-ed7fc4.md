语义首位漏掉两个同义问和一个精确 ASCII 标识问题。ASCII 正例首位为 3/4，词法为 4/4；语义前三找回 4/4。语义每问返回多个候选，9 个同义问的前三同时含 18 个非预期来源。因此不能只展示“前三全中”，或把总能返回结果宣传成可靠记忆。

没有校准语义拒答阈值。全部 12 个负例仍有候选，4 个完全无关问也全部如此。另一个明确分开的 4 源/3 问小诊断中，否定和更正各一问的首位正确，但其前三仍带旧约定/冲突来源。该小诊断不足以证明时间、否定或更正已经解决。

本轮没有事后挑选阈值、变更 gold 或训练这些问题。`real-encoder-ed7fc4.json` 保留各类别、负例和冲突指标；原 CI 完整摘要保留全部固定问题的候选顺序。

## 实测成本

GitHub-hosted Linux x86_64 CPU，2 编码线程、batch≤8。以下只适用于这份很小的合成库：

- 模型及 tokenizer 合计 95,332,206 bytes；Python 依赖环境 273,260,562 bytes
- 已验证本地文件首次加载 0.529 秒；不含下载，不承诺操作系统冷缓存
- 12 源索引构建 0.306 秒；52 问查询中位 29.1 毫秒、最大 33.6 毫秒，含现有本机读取链
- 主集 SQLite 249,856 bytes；额外诊断索引 94,208 bytes
- 每 50ms 采样的进程树 RSS 峰值 253,210,624 bytes（约 241.5 MiB）；编码进程自身 ru_maxrss 235,151,360 bytes
- 运行阶段 4.25 秒，71 次真实编码请求；重复查询缓存核验通过，272 次来源 fetch 均核对原文/快照
- 最长实际输入 36 tokens，额外超长输入在模型执行前被拒绝；没有静默截断

RSS 求和可能重复计入共享页，也可能漏掉很短的峰值；不是 cgroup 硬上限。这些数值不能直接外推用户机器、iGPU、长文档或大规模资料库。GitHub 计费未读取，不声称 Actions 免费。

模型锁验证固定 revision、ONNX SHA256，以及六个小文件的官方 Git blob hash 和长度；CI 已另外计算全部文件 SHA256，保存于结果 JSON。实际完整包版本/分发摘要在 `real-encoder-ed7fc4-dependencies.json`，不是把未固定传递依赖声称为跨时间完全相同。
