# 0.7 检索候选：词组、证据与字节预算

本次改动来自固定旧版的真实使用问题。公开回归只使用重新编写的合成等价样本；真实归档、场景、模型请求和评分仍单独保留，不进入仓库。

## 查询合同

- 连续中文按完整词组匹配；只有查询本身为单字时才匹配该单字。不会把两个不同的双字词仅因共享一个字就当作命中。
- 空格或标点分开的关键词都需要命中。英文按词边界、不区分大小写；支持中英混合、实体和标签。
- 这仍是词法检索，不承诺自然语言长问句的同义推理。MCP说明引导客户端使用简短关键词、必要时换词。可选已授权语义检索仍能补充非词法候选，并明确标记覆盖。
- 证据和状态使用有限排序权重，偏向相关的用户直接表述。无关事实不能凭“active”进入结果；专门询问建议时仍可检索助手建议。

## 合并与分页

同时命中的记忆和它引用的原始事件不重复占据首屏，`related_refs` 保留直达原话的入口；完整证据继续通过 `sources` 获取。多个不同记忆不会仅因共享一个来源而消失。此机制不跨不同查询隐藏已经看过的结果，也不静默替用户判定旧记忆已经过时。

先为多条结果保留可用片段，再均分剩余预算，防止第一条长回复独占首屏。`detail=context` 的单条摘要最多 2400 字节，`brief` 最多 240 字节；这是检索摘要策略，独立于工具响应安全上限，增大全局预算不会自动取消摘要长度限制。片段仍是原文连续字节范围，不是模型总结。按 `ref`、`text_range.start_byte` 和读取游标可核对全文。来源分组参与游标身份，换数据、授权或排名后必须重新搜索。

`status=no_matches`、`status=budget_exhausted`、`next_cursor` 和 `text_truncated` 是不同状态。预算不足返回 `recommended_min_budget`，可用该值重试相同查询或读取位置。预算指完整工具结果 JSON 的 UTF-8 字节，不是模型 token。32768 字节仍为当前工具单次响应上限；超过上限的正文使用分页，不宣称无限上下文。

## 验证界限

通用回归覆盖中文相邻字误命中、多词缺词、英文与混合查询、来源去重、相关用户事实与建议、历史状态、首屏分配、游标完整性及最小预算重试。旧版真实客户端的原始题目和对照指标保持冻结，新源码必须重新构建后复测；源码回归通过不能替代真实模型有效性结论。
