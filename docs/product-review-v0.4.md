# RecallCard 工作区整改方案

日期：2026-10-07。依据已交付 0.3 的真实原生截图、界面事件和用户反馈。本文是下一阶段方案，不表示新界面已经实现或验收。

## 要完成的主任务

把已保存的原话和有出处的记忆带到下一个 AI 继续工作。导入、搜索、阅读、核对来源、选择背景、交接应当是一条连续路径。用户不需要理解内部数据类型、工具名称或启动标签。

## 当前界面的问题

- **入口按模块拆分**：概览、会话与接续、查找与阅读、添加资料、整理记忆、记忆管理、连接与状态并列。找到内容、检查出处、处理记忆和接续需要多次重新选择
- **首次介绍占据日常工作区**：大幅宣传区、装饰与功能卡适合首次打开；已有资料时仍缺少明确的“继续上次工作”入口
- **导入没有落到成果**：成功后只显示新增数量，停在长导入表单。用户仍须找会话入口并再次选择刚导入的内容
- **列表难以比较**：搜索卡片以类型、摘要、时间和长内部ID为主，缺少会话标题、来源平台、原始角色；文字层级不能帮助判断命中是否相关
- **主操作被正文挤走**：接续表单位于全部当前页消息之后。消息越长，“带到另一个AI”越难找到
- **出处查证被管理字段打断**：记忆全文之后先排列状态、证据、保护、版本、多个时间与ID，原始出处常在屏外。需要查原话时仍要滚动或换页
- **返回会丢定位**：重新进入会话页会重新加载列表并清空选中会话。核对来源或设置后返回，不能自然继续
- **状态表达过重**：覆盖说明、权限提示与技术字段常驻，占据正文之前的大块空间。不能删掉这些信息，应将摘要留在关键位置、详细解释按需展开
- **新背景页延续同样问题**：继续增加一个独立入口和一组预览表单，会加重导航与阅读成本。因此保留已验证服务，暂停发布该页面

## 下一版结构

### 会话与记忆为主，操作靠近内容

主导航收为“会话”“记忆”；导入常驻为操作按钮，连接与设置放底部。已有资料时直接打开上次工作区或最近会话。首次空库提供一个主要动作“导入会话”，新笔记作为次要选择。

顶部固定搜索和当前资料范围。范围是权限边界，切换仍必须清除旧预览和批准。搜索、最近会话及记忆列表复用稳定的“列表—阅读区”框架，不引入新的独立工作区。

### 列表负责判断，阅读区负责核对

列表每行展示标题/正文摘要、平台/原始角色、时间、少量状态。搜索时显示命中附近原话。内部ID放入“详细信息”，需要复制时仍可取出。

阅读区首屏显示标题、正文、来源摘要和“带到另一个AI”。原始出处可以在当前阅读区展开，保留会话标题、角色、原始时间和“定位到这条消息”。来源原话和模型生成的解释须清楚区分。

列表与正文各自滚动；不要把整个窗口做成长表单。窄窗口改为列表/详情切换，有明确返回，并恢复原列表位置，不能只是把两列上下堆起来。

### 接续作为当前任务的一部分

点固定的“带到另一个AI”打开接续面板：先写下一步目标，随后检查所选会话、已带上消息数、背景摘要与覆盖限制。完整实际文本可展开；“复制接续内容”始终在固定操作区。

“每次接续带上”放在记忆详情与接续面板中；记忆列表提供“已选背景”筛选。沿用已实现的来源核验、保护、预览与撤销服务，不新增顶层“随身背景”导航。

这轮继续使用现有的单会话、有界消息交接。跨会话任意材料篮、历史草稿保存、图形化语义检索及同步分别列为后续，不用界面暗示它们已经可用。

### 导入与整理变成清楚的步骤

导入依次显示“选择文件 → 选择会话与预览 → 保存结果”。每步只突出一个下一步按钮，覆盖摘要保持可见、详细诊断可展开。成功后显示新增与重复数量，直接打开刚导入的会话；多会话导入则显示本批结果列表。

整理从当前会话或记忆的操作进入，按“生成任务 → 粘贴结果 → 核对差异”顺序呈现。核对差异时同屏显示来源原话，避免只列引用ID。保护变更和遗忘保留专门确认。

## 状态与安全要求

- 当前查看、当前勾选和待保存变更采用不同状态，不能混淆
- 同一资料范围内返回列表保留搜索、已选条目和滚动；返回后重新检查可见性，失效内容不得继续出现在预览
- 资料库/范围改变后仍清除旧正文、复制内容、写入预览及批准
- 未保存变更需要明确的“继续编辑 / 放弃”选择；取消不丢输入
- 复制成功显示已复制及来源范围，不声称目标AI已接收；最终发送始终由用户完成
- 正文使用可读字号和对比度；键盘聚焦、列表移动、打开、返回都要可用。装饰不与任务内容争夺首屏

## 验收任务

用合成的 53 会话备份、多角色、长标题、长正文与缺失时间覆盖常见密度，不将真实个人历史提交为测试素材。

1. 导入两段会话后，无需查找菜单即可打开本批成果
2. 搜索一句原话，查看相邻上下文和出处，再返回时保持原来的查询与位置
3. 查看一条记忆，从同一阅读区核对原话并选为背景；检查实际内容后可撤销
4. 选一段长会话，首屏即可找到接续操作；核对消息覆盖与背景、复制完整文本，不必滚到消息底部
5. 在检查来源或编辑目标后返回，保留当前任务；换资料范围后旧内容和批准失效
6. 重复点击、取消、文件变化、遗忘、窗口变窄及键盘操作不产生意外写入或错误复制

先本地验证实际模块和服务合同，再合并执行一次必要的原生窗口验收。截图应包含有足够数据的列表、展开出处与接续面板，不能仅用欢迎页证明可用性。
