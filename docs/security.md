# 安全边界

- 公开仓库只包含程序与合成 fixture；真实对话、资料库、密钥不得提交
- 客户端权限在进程启动时绑定 scope；请求只能在该范围内操作
- 模型可用的四个工具均只读；不执行检索内容中的命令、路径或自然语言指令
- 检查记录编号、符号链接及祖先目录、结构版本、内容摘要、来源、大小上限与版本冲突
- 使用临时文件、刷盘、原子替换与操作系统锁，避免读到半文件；Git 冲突与损坏不会被静默修复
- 原始 Event 写盘前过滤常见密钥模式和结构化秘密字段；这是启发式保护，不保证识别所有秘密，用户仍需检查来源
- 不获取隐藏推理；日志中的 thinking/redacted_thinking 不进入正本
- Memory 的来源标签和模型评分不授予更高权限，也不证明自然语言结论为真
- MCP 权限无法约束另有整个文件系统访问权的 Agent；需要隔离时只提供受限工具，不提供完整 Vault 路径
- 第一版主要保护误操作、恶意输入和不可信模型输出；不声称抵御能持续修改同一操作系统账户文件的本地攻击者
- Browser 最终发送必须由用户完成；网页内容的自动采集还须独立遵守服务条款
- Git remote 是敏感资料存储。初始化不配置远端；不要误把公开代码仓库用作私人 Vault 远端

接口依据：[MCP stdio](https://modelcontextprotocol.io/specification/2025-11-25/basic/transports)、[MCP Tools](https://modelcontextprotocol.io/specification/2025-11-25/server/tools)。协议版本兼容性与真实宿主行为需分别验证。
