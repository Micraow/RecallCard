# 新桌面界面：结构、状态与验证边界

日期：2026-10-08。此文是 v0.6 工作分支实施记录，不是已完成产品或发行声明。

## 为什么重新划分界面

旧版把导入、挑选、生成任务、复制、粘贴与发布作为主内容；用户必须维护内部流水线。新版主内容为可读的记忆与来源，操作放在选中对象附近。稳定导航为记忆、来源、连接、活动，设置独立放在底部。

参考了 Linear 的稳定应用壳与信息层级、TencentDB Agent Memory 的记忆列表和阅读区、WorkBuddy 项目的范围与继承说明。不引入团队账户或图数据库，不复制其品牌和图片。公开参考链接在 `../product-reboot-v0.6.md`。

## 技术边界

- React 负责组件生命周期与局部交互；TypeScript 明确数据、错误和空状态。
- Vite 只负责 TSX/CSS 构建，不引入服务端渲染、路由框架或独立数据库。
- `service/client.ts` 是唯一 Tauri 调用入口，绑定本机 session 与资料范围。前端不接受自由路径、不实现导入算法或权限算法。
- `contracts.ts` 镜像 Rust 应用任务 DTO；稳定 schema 不一致时显示错误，不把未知响应变成零条记录。
- `hooks.ts` 丢弃已离开的资源请求，隔离范围和空间切换；任务按真实状态轮询，不声称使用尚未存在的事件订阅。
- `pages/` 是阅读、来源、连接与活动的领域页面；`components/` 是共享控件。
- 正常入口 `index.html` 只调用 Tauri。缺少本地服务时显示无法访问，不自动切入示例模式。
- `demo.html` 是独立合成数据验证入口。生产构建仅包含 `index.html`；CI 检查示例身份没有进入发行资源。演示页一直显示醒目的合成数据标识。
- 旧 `desktop/ui` 保留。新构建产物为 `desktop/dist`，不会覆盖旧源文件；旧原生包和真实资料未改动。

## 交互与真实性

### 记忆

列表与阅读区常驻，按需展开出处。每条记忆显示证据性质、版本、时间和保护状态。纠正先审阅再保存；受保护内容有单独默认未勾选的确认。停止召回先显示受影响记忆与事件数。深链详情从后端读取隐藏状态，不因为离开管理列表而显示成有效记忆。

### 来源

只有一个「添加来源」入口，文件由原生选择器提供。所有导入走共享 ImportService。错误在对应任务旁展示文件、成员、原因、下一步与已提交边界；未知总量只显示已读取字节与真实计数。已保存原话无需等待整理。分支或时间关系未知时明确说明。

### 连接

生成 MCP 配置与注册 Native Messaging 都只说明配置发生了什么。没有宿主调用回执时一直标为未验证。扩展写入权限默认关闭，网页最终发送由人点击。

### 活动与设置

导入任务支持查询、暂停、继续；运行状态来自相同 Rust DTO。后台整理状态来自 MemoryRuntime。模型配置、凭据、安全授权与守护进程正在接入，当前切片不提供无效开关，不把配置成功等同实际服务运行。

## 构建与测试

在 `desktop` 目录：

- `npm ci --ignore-scripts --no-audit --no-fund`
- `npm run typecheck`
- `npm run build`
- `npm run test:contracts`
- `npm run test:frontend`

本轮本地 TypeScript、生产构建和 9 个纯合同测试通过。当前执行环境的 Chromium 启动被 socket 权限拒绝，未继续本地浏览器路线。独立的离线 DOM 检查禁止 socket，仅验证组件逻辑，不代替浏览器布局或原生窗口验收。

首轮合成 Chromium 验证通过 14 个场景，运行 https://github.com/Micraow/RecallCard/actions/runs/37716937875 。截图审查发现次级文字过淡、窄窗截图等待不足和错误恢复按钮不准确，随后进行了以下修订，等待第二轮精确源码验证：

- 设计变量统一为中性文字，正文 15 px，元信息 12 px；正文对白对比度 8.53:1，元信息 5.30:1，选中行元信息 4.62:1。
- 1000 px 以下切换列表与阅读两层，820 px 分别在内容加载后截图。
- 损坏、变更或不支持的来源改为重新选择来源，不再显示泛化的继续。
- 合成资料包含实际完成、时间变更、版本范围、暂未确认和被替代的旧计划。
- 后台刷新保留正在编辑的草稿；CI 新增字号/对比度断言。
- CI 安装中文无衬线字体，避免测试宿主字体缺失造成的回退。

浏览器合同覆盖：生产入口服务缺失；密集记忆及来源；导航与返回；搜索；受保护更改；取消和焦点恢复；遗忘/恢复；导入结构化错误；未知总量；暂停/继续；重复点击；文件选择取消；不可用服务；未验证连接；范围隔离；空态；820 px 与窄窗；键盘搜索。截图仅含合成数据。
