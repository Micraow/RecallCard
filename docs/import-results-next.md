# 整批导入后直接查看这批会话

本改进基于 110e5b4，保存于独立工作分支。不是已交付 0.4 或冻结 0.5 安装包的验收声明。

## 可完成的路径

1. 选择一份或多份导出文件，检查数量后一次批准导入
2. 导入完成，或明确暂停后，点击“查看本批会话”
3. 在本批列表中直接读原话，再点击“带到另一个AI”，检查并复制交接文字，自己发送

重复导入没有新增消息时仍能打开本批已有资料，不会被带到无关的最新会话。部分失败或中断时只列出已核实处理且目前可访问的会话。没有可读成果时说明当前为空，不借用全部会话填充；读取失败有重新读取入口。

超过一页的本批会话可以分页。进入其他工作区或回到导入记录后再次查看，重新核实权限，并保留仍可见的选中会话、当前页、阅读位置和下一步目标。离开批次可点击“查看全部会话”。

重新打开程序后，进入导入页的“查看导入记录”，已完成和未完成任务都能再次查看；未完成任务仍须明确点击继续。不会自动恢复写入。

## 事实与访问边界

本批成员由本机任务记录与冻结输入核实，界面不从平台标题或会话时间猜测。显示字段来自当前可见原文；遗忘、撤回、旧版本被替代及范围限制立即影响下一次读取。只读成果查看不改写资料和任务，也不依赖原始下载文件仍在。

列表的消息数量只统计本批当前可读成员。打开会话后读到的全部当前原话可能包含其他批次，界面可展开“本批会话范围”查看说明。异常退出前已经写盘但尚未记录进度的部分不计作已核实成果，可从全部会话查找，或明确继续任务完成核对。
