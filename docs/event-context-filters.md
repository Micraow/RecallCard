# 显式检索原始意图

本能力只增加条件过滤，不改变默认词法算法，不启用语义模型，不代表自然问句召回或自动记忆整理已经达标。

通过 CLI 的 `--role user` 或 MCP `search.event_filter.role=user` 查找用户原始要求、计划与决定；查双方讨论、推导或助手建议时省略此条件。程序不会从“我”“最终”等问句词语猜测并强制切换角色。

- `occurred_from` 与 `occurred_until` 使用 RFC3339 发生时间，包含边界；不是捕获时间。缺失发生时间的 Event 不匹配时间条件。
- `on_current_path=true/false` 只匹配导出明确记录的路径标记；未知不匹配。`false` 的多个结果仍可能属于不同平行分支，不能合并成一条时间线。当前路径标记不是用户采纳建议的证据。
- 原有 `session_ref` 可把检索收窄到明确会话；`as_of` 仍是发生/有效时间过滤，不是历史数据库快照。
- 任一非空 Event 条件使 `target=all` 只保留 Event；`target=memories` 搭配这些条件会明确报错。Memory 没有假定的发言者；请用 `sources` 逐一核对原始 Event 的 role、origin、时间与正文。
- 空结果只表示当前查询与条件未命中。调用方可显式去掉角色、时间或路径条件后重查，必须让使用者知道范围已改变，不能自动越权扩大 scope。
- 分页游标绑定全部条件；改变条件须重新开始。新记录写回、隐藏和来源权限仍在下一请求重新检查，没有跨请求授权缓存。

检索结果提供结构化 `role` 与已知 `on_current_path`。这些是来源归属，不是用户永久属性或事实正确性的担保。用户提供的代写/招募文案仍要结合上下文判断，不可仅凭第一人称推断个人事实。

## 沿来源继续核对

CLI `read` / `sources` 的 `--include-adjacent` 或 MCP 同名布尔参数，可对单个 Event 显式请求：

- `previous_ref`、`next_refs`：已授权原始图的相邻节点，最多列出三个后继，并返回实际数量。
- `next_user_ref`：沿唯一、可验证的路径跳过最多 64 个非用户节点找到的下一个用户消息。分叉或隐藏中间节点会停止。当前节点明确 `on_current_path=true` 时，只沿后继同样明确为 true 的边继续，未知/非当前后继留作分支选择；当前节点没有 true 标记时，可沿唯一显式原图边继续，但这只证明可达，不声称该路径当前选中，也不猜测“后来一定修正了什么”。
- `branch_choices`：最多三个其他可读分支选择；有多条候选时必须明确选择，不能按时间较晚就覆盖不同分支的事实。

这些字段只是导航，不证明新消息确实修正旧消息。读取目标后仍要核对 role、时间、主题和原话。默认关闭导航以保持普通正文读取预算；开启后引用信息也计入同一字节预算，可能需要继续分页。

每次请求仍在当前读取锁内重验 scope、隐藏、修订和来源图。来源的 provider、账号、原始 conversation ID 都必须相同；相同自定义 `session_id` 不能把两段不同对话连起来。来源图改变会使导航页游标失效。原始记录没有关系或父节点不可读时不猜边。旧记录的 provider message_id 重复时，`ambiguous_source_identity` 标出歧义，不能据该外部编号猜父节点；若记录另有直接指向唯一 canonical Event ID 的 `reply_to`，仍可沿这条明确且已授权的边导航。循环关系明确失败。

Memory 需先 `sources` 获取原始 Event，再逐个请求导航，不能把多份来源自动拼成一条用户决策时间线。没有修改 GUI，也没有据此宣称自然问句质量或记忆整理能力验收通过。

## 有界紧凑投影

单个 Event/Memory 的 `read --detail compact`（MCP `detail=compact`）优先保留正文、角色/时间、范围、字节位置、snapshot 和游标；详细原始来源标识可按需用默认 `full` 读取。`sources(memory)` 的 compact 只返回可继续读取的来源引用，不展开每条完整 Event。

紧凑投影不会摘要或改写正文，不把未显示的信息当作不存在。保留缺失正文、原捕获完整度、必要记忆有效期和证据类型；相邻引用仍使用同一份当前授权快照。切换 full/compact 模式须重新开始，不能复用另一模式游标。小预算放不下必要元数据时明确返回 budget_exhausted；正文裁剪仍给出 truncated、text_range 和续读游标。

字节上限针对返回 JSON；CLI 的行末换行单独构成传输开销，不是模型 token 或计费 token。默认 full 模式保留兼容行为。
