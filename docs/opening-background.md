# 开局背景

首页的“开局背景”无需先填写问题。它把已有的稳定背景维护 API 接回可见界面，使用 `Context::bootstrap` 相同投影，没有增加模型调用。

## 使用

1. 首页选择“开局背景”，查看当前范围的实际文字、来源版本、UTF-8 字节数以及截断提示。
2. 从已有 Memory 选择有长期价值的信息。点击“加入开局背景”先展示变化后的真实背景，再确认。加入会保护该记忆；不修改正文、证据和时间。
3. 复制时重新读取当前投影。若正文或引用版本改变，先显示新预览，等待再次点击，不悄悄复制另一版。
4. “移出开局背景”只取消默认选择。受保护记忆需另外勾选本次批准，正文、来源和保护仍保留。取消预览不保存修改。

后台只返回当前范围内可访问的记忆。过期、待确认、撤回、来源被遗忘等情况会明确说明；已选项超过默认字节预算时，以实际预览和完整来源引用为准。普通会话尚未整理成 Memory 时不会伪造事实，也不会把助手建议改标成用户决定。

## 哪些入口采用

- 桌面的“准备这次对话”自动把这份稳定前缀放在所选来源之前。
- MCP 的 `bootstrap` 工具返回同一投影；初始化说明建议宿主在开始、恢复、压缩后调用。服务器不能保证所有宿主执行或模型采用。
- 网页扩展已有“准备使用说明”和获准后的草稿接力，可准备相同背景。手动复制可用于任意 AI；最终发送仍由用户执行。真实登录网站未在合成验收中证明可用。
- 受管理的 `connection-context` 文件入口当前仍使用另一个有界 profile/会话目录选择器；此修复不冒称已统一全部入口。

本阶段不实现普通会话自动摘要、自动给所有网站注入背景或外部自动发送。原始聊天、未选 Memory 和附件原件不出现在这份开局复制正文里；需要时使用按需召回。

## 验证

合同测试覆盖复制前全文/来源重验、关闭和换范围后的迟到结果、无效返回、纯文本渲染、精确取消和 session/scope 绑定。Rust 使用真实 Vault 验证取消、过期/遗忘、保护确认与投影一致性。

原生验收脚本通过真实首页和 Tauri：无 Memory 如实显示 → 选择合成 Memory → 取消零写入 → 确认并核对系统剪贴板全文 → 明确批准移出、检查正本保留。脚本中的 Memory 是显式合成测试准备，不是模型自动整理的成绩；执行结果以对应提交的 CI 产物为准。
