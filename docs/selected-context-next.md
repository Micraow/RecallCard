# 从搜索结果带走相关原话

本阶段保存在独立工作分支，尚未进入已冻结的 0.5 安装包。

## 使用路径

在顶部查找资料，点击“带走这些资料”。默认按当前结果列表顺序选择前三条，最多八条，可以增减。右侧仍是原来的阅读位置，不增加工作区。窄窗口可点击“调整所选资料”返回列表，调整后再次打开。

写明接下来要做什么，检查每条资料的角色、时间、原文与出处。准备后的内容包含实际随身背景、明确区分的原始消息和整理记忆；点击“检查完整交接内容”可读到将被逐字复制的全文。复制后由用户决定粘贴到哪个 AI，并亲自发送。返回搜索保留当前查询、资料类型、阅读对象和列表位置。取消不新增或修改资料。

## 原文与访问边界

界面只提交明确的 Event 或当前 Memory 版本引用；服务重新读取正文，不信任搜索片段。用户原话、AI 建议、工具结果分别标记，未知时间保持未知。整理记忆带状态、证据性质、有效时间及原始出处，不冒充逐字原话。多会话选择顺序不是时间线，不能据此推出先后或因果。

复制之前再次读取并比较完整文字、稳定前缀和背景版本。资料遗忘、撤回、修订或访问范围变化后拒绝旧预览，必须重新准备。切换资料库、范围、重新查询或明确保存记忆时移除旧选择与预览；已离开页面的旧控件不能继续复制。

## 长度与背景

输出实际以固定说明及默认 MCP Bootstrap 的 stable_text 开头，目标与选文排在后面。它使可重复前缀保持稳定，但不保证目标服务的缓存命中或计费方式。

现有协议参数名 budget_tokens 沿用兼容命名；此入口使用整个 JSON 响应的 UTF-8 字节数作为保守上限，budget_unit 明确为 conservative_utf8_bytes，默认 32768。它不是特定模型 tokenizer 的精确 token 数，界面不将其写成精确 token 用量。

超长资料会节选，未纳入的引用单列说明，来源和证据性质保留。若预算未容纳任何所选资料，禁用复制。文件记录未保存正文时明确说明，不能补写不存在的内容。
