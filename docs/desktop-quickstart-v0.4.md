# RecallCard 桌面 0.4：找到原话，带走背景

打开应用，创建资料库并选择一个空文件夹。已有资料库可以直接打开。不用先配置账号、API、向量或同步。

## 先完成一次接续

1. 点顶部「导入会话」，选择备份 ZIP 或会话文件。ZIP 无需解压；勾选会话、检查角色和原始时间，再确认导入
2. 保存后直接进入本批会话。点击一条阅读原话；顶部搜索可查找具体决定或片段
3. 点阅读区标题栏的「带到另一个AI」，写下下一步目标，检查背景和消息覆盖，复制接续内容到目标 AI，自己发送

已有会话即可接续，不必先整理记忆。长会话只携带有界的消息，面板会显示带上多少；展开完整预览可检查实际文字。

## 核对来源与记忆

「会话」用于阅读原始对话；「记忆」用于查看整理后的长期信息。来源在阅读区按需展开，保留原始角色与时间。时间缺失会标为未知，不拿导入时间冒充。

搜索或查看来源后返回，会保留当前浏览位置。切换资料范围或资料库会清除旧预览与批准；资料被遗忘或撤回后，不能继续复制旧内容。

想让一条记忆每次接续都带上，在记忆区选择背景或从接续面板打开「设置随身背景」。先核对全文与出处，再检查实际带入文字并确认。加入时同时保护记忆；取消选择后正文、出处和原有保护保留。

## 把重要内容整理下来

从会话或阅读区选择来源，进入「整理记忆」：

1. 生成完整整理任务，检查并复制到自己选定的 AI
2. 自己发送，再把完整结果粘贴回来
3. 检查每项差异与证据，确认后保存

软件准备完整指引和结果格式，无需自己编写提示词。修改受保护记忆需要额外勾选确认；来源或旧版本改变后必须重新审阅。

在记忆详情可纠正、保护、遗忘或恢复。遗忘会影响共用来源的其他记忆，预览会显示影响；资料文件保留。修改正文或选择背景不会把 AI 建议自动变成用户事实。

## 文件与浏览器

支持 ChatGPT 官方数组、单会话 JSON、包含这些文件的普通 ZIP，以及 RecallCard 扩展导出和 Claude Code 日志。每批最多 5000 条消息；同一来源版本重复导入会跳过。

扩展可在 ChatGPT / DeepSeek 中读取当前可见消息、预览并导出。未连接本机也能导出文件；需要直接保存时，再到「连接与设置」配置。可见消息始终只代表捕获的部分历史。

## 打开安装包

Arch Linux 优先使用 AppImage，Ubuntu 可安装 deb。便携 ZIP 解压后运行「运行桌面版.sh」，系统需要 Git、GTK 3 和 WebKitGTK 4.1。不要混用不同提交号的程序。

云端标准 Linux 与用户自己的 Arch/KDE Wayland 是不同环境。真实登录态网页和已安装扩展的兼容性，以实际连接结果为准；浏览器禁止安装时不修改安全策略。
