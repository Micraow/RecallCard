# 不依赖网站的上下文交接

首页可直接输入当前问题，点击「准备这次对话」；也可以按问题搜索，在结果上点击「带到任意 AI」。默认选择前 8 条相关结果，允许勾选调整；修改问题或选择后需要重新预览。

交接窗口可以「按这个问题找资料」。修改问题后旧候选会明确失效，必须重新检索才可预览和复制；空结果或失败不会悄悄沿用上次选择。每条候选显示用户/助手角色、原文摘录和引用，同一会话的不同消息仍可辨别；前 8 条只是默认选择，第 9 条及后续候选可以换选。

本次检索覆盖说明会显示实际词法、本地语义、已批准云语义或退化状态。复用已有检索配置，不新增服务或授权。当前桌面语义候选只覆盖已建索引的 Memory，原始聊天 Event 仍通过词法查找；问题入口显式使用 natural_question 字面候选模式，连续汉字至少 6 字且没有双引号的问题不再依赖问号触发；普通关键词入口保持原匹配合同。该改进不代表已解决同义改写或全量原始聊天的语义召回，也不把空结果当成“以前没聊过”。

预览显示当前空间、来源、用户原话或 AI 回答、完整复制文字的 UTF-8 字节数，以及未选择、预算未带入和截短的范围。稳定背景也包含在完整预览中；勾选的受支持 UTF-8 附件正文会作为独立文件内容带入，附所属 Event 引用和原件 SHA-256，role 保持空，不等于上传者原话或用户事实。仅带入选定附件，不附带原始文件，也不顺带复制未选父消息正文。附件显示的时间继承父消息，不代表文件创建时间。选文不代表完整历史或同一分支。

点击「核对并复制上下文」时重新读取当前正本。附件与分页共用安全读取校验：当前所属消息、空间、修订/遗忘状态、原件关联、大小、SHA-256、UTF-8 与安全文本类型均重新核验；不支持、损坏、缺失或超过单件 1 MiB 的附件拒绝准备，不沿用旧正文。最多选择 8 条；单件关联核验仍有 256 条声明 / 16 MiB 读取边界，全部选择最坏 128 MiB，不做全库附件扫描。最终复制包按完整 JSON 的保守 UTF-8 字节预算截短并报告未带入引用。若资料变化，先展示新预览，不复制旧内容；若重新读取失败，不写剪贴板。关闭或切换页面后，迟到结果不会继续写剪贴板。复制操作由系统剪贴板承载，之后的剪贴板历史、跨设备同步、其他应用读取受操作系统设置影响；RecallCard 不承诺撤回已复制的文字。用户将文字粘贴到任意 AI，并自行发送；此流程不新增站点权限、不登录网站、不覆盖网页草稿。

收到普通回答后，在首页点击「粘贴 AI 回答」，手动粘贴，检查脱敏预览并确认。无需协议标记。保存为新的 assistant / assistant_output Event，独立来源为「手动粘贴的 AI 回答」；不伪造原平台、原会话、时间、父子关系或已核验身份。

该来源可搜索并返回原文，不会进入自动记忆整理，也不能单独作为 user_explicit 或 observed 事实证据。相同确认令牌重复调用只保存一条 Event。关闭或取消回答预览会撤销该令牌；旧窗口迟到的取消不会撤销新的预览。关闭资料库或生成新的回答预览后，旧令牌也失效。若正文混有 RecallCard 上下文或整理协议标记，会在预览阶段明确拒绝，避免将复制的资料当作新回答回流。

本跨平台复制粘贴流程不自动读取网页、填框或发送。这些手动步骤已与已有浏览器扩展能力分离，不代表任何实际网站已验收。界面与原生验收仅使用合成资料；普通回答保存不请求外部模型。

## 可选网页填框的确认边界

已有扩展的填框路径现在等待两个绘制帧和短暂刷新时间，再比较原草稿与整段新增资料的完整文本，只归一化 CRLF/CR 换行；富文本还核对可见换行、原节点顺序和格式。可见目标必须唯一、可编辑并通过遮挡检查。填框与网页发送仍然分开。

若尾部被截断、原草稿被框架改写、输入框被重建或会话变化，扩展不返回成功，也不回滚覆盖用户内容；核验中或失败后的页面重置只停止操作，不自动移除草稿。写入后结果不明时，本页面后续自动写入停止，用户应先人工检查草稿并使用手动复制；重新加载页面才会解除这次安全停止。没有新增网站权限，仍只支持清单中的明确平台和路径。

原创合成 DOM 回归覆盖这些行为；实际浏览器结果以对应提交的 CI 为准，不能据此宣称真实账号中的编辑器版本或登录状态已验证。

附件复制回归使用原创合成正文，覆盖混选、来源标签、当前授权/版本、原件篡改与链接、重复关联、八条 UTF-8 预算、只读性及复制前复核。前端合同不等同于真实系统剪贴板、实际 AI 网站粘贴或真实用户验收。
