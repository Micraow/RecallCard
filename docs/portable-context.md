# 不依赖网站的上下文交接

桌面端按当前问题搜索，在结果上点击「带到任意 AI」。默认选择前 8 条相关结果，允许勾选调整；修改问题或选择后需要重新预览。

预览显示当前空间、来源、用户原话或 AI 回答、完整复制文字的 UTF-8 字节数，以及未选择、预算未带入和截短的范围。稳定背景也包含在完整预览中；附件原件与附件正文不会复制，选文不代表完整历史或同一分支。

点击「核对并复制上下文」时重新读取当前正本。若资料变化，先展示新预览，不复制旧内容。关闭或切换页面后，迟到结果不会继续写剪贴板。用户将文字粘贴到任意 AI，并自行发送；此流程不新增站点权限、不登录网站、不覆盖网页草稿。

收到普通回答后，在首页点击「粘贴 AI 回答」，手动粘贴，检查脱敏预览并确认。无需协议标记。保存为新的 assistant / assistant_output Event，独立来源为「手动粘贴的 AI 回答」；不伪造原平台、原会话、时间、父子关系或已核验身份。

该来源可搜索并返回原文，不会进入自动记忆整理，也不能单独作为 user_explicit 或 observed 事实证据。相同确认令牌重复调用只保存一条 Event。关闭或取消回答预览会撤销该令牌；旧窗口迟到的取消不会撤销新的预览。关闭资料库或生成新的回答预览后，旧令牌也失效。若正文混有 RecallCard 上下文或整理协议标记，会在预览阶段明确拒绝，避免将复制的资料当作新回答回流。

本跨平台复制粘贴流程不自动读取网页、填框或发送。这些手动步骤已与已有浏览器扩展能力分离，不代表任何实际网站已验收。界面与原生验收仅使用合成资料；普通回答保存不请求外部模型。

## 可选网页填框的确认边界

已有扩展的填框路径现在等待两个绘制帧和短暂刷新时间，再比较原草稿与整段新增资料的完整文本，只归一化 CRLF/CR 换行。可见目标必须唯一、可编辑并通过遮挡检查。填框与网页发送仍然分开。

若尾部被截断、原草稿被框架改写、输入框被重建或会话变化，扩展不返回成功，也不回滚覆盖用户内容。写入后结果不明时，本页面后续自动写入停止，用户应先人工检查草稿并使用手动复制；重新加载页面才会解除这次安全停止。没有新增网站权限，仍只支持清单中的明确平台和路径。

原创合成 DOM 回归覆盖这些行为；实际浏览器结果以对应提交的 CI 为准，不能据此宣称真实账号中的编辑器版本或登录状态已验证。
