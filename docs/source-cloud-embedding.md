# 普通对话与附件的可选云向量提供器

来源语义索引可明确选择本机服务或 HTTPS OpenAI-compatible embedding 服务。接口、模型、维度、版本、tokenizer/池化标识和输入指令均由用户填写；不绑定 BGE，也不预设 Qwen 接收者。BGE 仅用于已有独立合成 CI。协议兼容不代表已真实调用或验收某个供应商。

## 明确批准与发送范围

桌面来源索引设置增加云配置入口。普通 Event 正文、附件正文、新问题三项默认关闭，分别批准，审阅界面再次列出接收接口、模型、当前 scope、各类数据和月度预算。其他 scope、本机索引、旧 Memory/query 云批准都不能自动授权此路线；切换提供器重新审阅。附件仍是独立来源，`role:null`，保留父 Event 引用，不变成上传者原话。

保存配置不建索引、不发送探测请求。随后明确点击更新已批准资料索引才发送当前 scope 的可见来源片段；已批准的未缓存新问题可在桌面或已有授权 MCP/浏览器来源检索时发送。仅 Event 批准不允许附件发送。安全文本提取、父事件可见性、scope、修订替换、撤销、对象摘要和 UTF-8 范围继续复用现有验证；没有新增 PDF 提取或 OCR。

云配置需要明确同意保存或使用该向量目标的系统保护凭据。密钥只经本机配置调用进入既有保护存储；界面不回显，配置 JSON 不保存密钥，不能借用整理模型凭据。系统保护存储不可用就拒绝启用。停用阻止后续发送并使配置/索引访问失效，已经开始的请求不能撤回，供应商可能仍计费。此功能实现不授权开发者读取任何真实凭据或发送真实资料。

## 宿主边界、缓存和预算

长期 Python 索引进程没有云凭据。需要新向量时只提出严格的宿主编码请求；Rust 根据原始作业、当前批准和可见正本重建允许的输入，绑定 scope、模型空间、来源 epoch、角色和实际片段。长期进程不能自行选择接收者、数据种类或正文。单作业至多一次回调，输入最多 4 条且总向量值至多 8192；输入帧 64 KiB、向量响应 256 KiB，拒绝重复字段、非有限值、错误维度与多余消息。

宿主对实际 HTTP JSON 请求体的 UTF-8 字节预留预算，随后启动只处理一次请求的独立子进程，清空继承环境并使用 Python -I/-S；这不是操作系统网络沙箱。仅向该一次性进程的环境注入目标 API key，密钥本身没有新增的短期有效期，固定 HTTPS 接口与批准种类，不使用代理、重定向或自动重试；一次性输入结束后关闭 stdin。原问题/片段的模型指令只添加一次。编码前后均复核批准、配置、来源与截止时间；网络期间不持 Vault 锁。超时或任何云错误都拒绝本次语义结果，不悄悄改供应商，也不在云错误时隐式启用词法降级。

缓存命中不读取密钥、不预留新请求、不发送网络；仍重验当前配置、独立批准和来源。云缓存结果显示 `query_encoding:cache`，覆盖信息仍标云来源提供器，不能把有云来源的索引误称为完全本机。已有本机服务的词法降级规则不改变。

来源请求与旧 Memory/query 请求共用整个 Vault 的持久月度账本和锁；不同批准的限额不是独立可叠加的余额。每次请求按其当前批准的限额核对共享累计用量，用户提高某项限额可能允许更多后续请求。失败预留不退，重启、重新批准、换目标或撤销不清零；无限模式仍计量。预算限制请求数和请求体字节，不是供应商账单金额保证。

## 验证范围

新增测试只使用原创合成文本、内存凭据存储和独立测试副本的注入 HTTP Transport；不读取真实 keyring，不访问云模型。覆盖独立批准、旧批准不继承、共享预算并发、实际请求体计量、缓存零发送、失败零重试与不退款、等待期间撤权和原件变更、类型/维度/响应边界、配置切换及前端两步确认。Rust 集成与原生界面结果以对应提交的 CI 为准；合成合同通过不能当作真实 Qwen 联通、语义质量、费用或用户验收。
