# 随身背景：每次接续带上

“随身背景”让你选择长期有效的重要记忆，例如沟通习惯、项目约定或持续任务的背景。选择之后，默认启动背景与会话接续会使用同一份内容；不会要求记住内部标签。

## 怎么用

1. 打开资料库，先选顶部资料范围，再进入「记忆」中的「选择背景」。切范围会回到「全部记忆」，可重新点「选择背景」
2. 在已有记忆中点击「查看全文与出处」，核对原始角色、时间与证据性质
3. 勾选「每次接续带上」，点击「检查随身背景变更」，阅读保存后的实际文字
4. 确认保存。受保护记忆的变更还需要单独勾选确认

一次审阅并保存一条记忆；改选另一条会替换尚未保存的选择。没有记忆时，先从保存的会话生成整理任务并审阅结果。新增背景选择会保护记忆，但不会修改正文、时间、出处、证据性质或事实状态。

保存后可从会话标题栏的「带到另一个AI」继续原任务，也可直接复制当前实际背景。复制到网站后，该网站可以读取内容；最终发送仍由自己完成。内容带有上下文标记，重新采集时不会误当作新的用户事实。

## 实际带上什么

页面预览、默认 MCP 启动背景、默认会话交接和扩展启动说明使用同一投影与默认长度。客户端主动请求其他长度时，其结果可能不同。

只带当前范围中有效、可访问、已选择且受保护的 Active 记忆。AI 建议保留证据标注，不会因为选择就升级为用户事实。待确认、失效、撤回、被遗忘或来源被遗忘的内容不进入实际背景。

默认长度有限。正文、证据标注与引用按整条保留，放不下的记忆不带入，并显示截断提示。已选择数量不等于实际带上数量，以页面预览为准；其他内容仍可按需检索。

## 取消或更正

取消「每次接续带上」，检查并确认后即可移除。记忆及原有保护保留，可随时再次选择。已选择但后来过期的可见记忆也能取消选择。

在「记忆管理」修改普通标签不会悄悄取消背景选择。更正内容、遗忘或撤回后，下次读取与复制会重新核对。审阅之后资料、权限、来源或有效时间发生变化，旧确认会失效，须重新检查。
