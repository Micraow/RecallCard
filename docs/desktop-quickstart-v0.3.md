# RecallCard 桌面 0.3：先导入，再继续

打开应用，创建资料库，选择一个空文件夹即可开始。暂时不用设置账号、API、向量或同步。

## 把已有对话放进来

进入「添加资料」，选择对话文件或备份 ZIP。ZIP 不用先解压：应用先列出会话标题、消息数量和角色，默认不勾选。选好一批，点「预览所选会话」，检查原文、来源和时间，再确认导入。

支持 ChatGPT 官方数组、单会话 JSON、包含这些文件的普通 ZIP，以及 RecallCard 扩展导出和 Claude Code 日志。ZIP 中的 Markdown 副本、隐藏推理、非当前分支及其他跳过内容会显示覆盖说明。原时间缺失时保留未知，每批最多 5000 条消息；同一来源版本重复导入会跳过。

正在 ChatGPT / DeepSeek 网页聊天时，可以通过扩展读取当前可见消息、选择后导出，或在获得本机保存许可后直接保存。扩展导出无需先完成本机连接。

## 换一个 AI 接着做

在「会话与接续」选择已保存的对话，填写接下来要做什么，生成交接内容。检查后复制到目标 AI，自己点击发送。

不必先整理记忆。交接带上已保存的原话、角色、出处和覆盖说明；长会话只包含有界的最近消息。

## 把重要内容整理成记忆

从会话或阅读区选择来源，进入「整理记忆」：

1. 点击「生成完整整理任务」，检查并复制到自己选定的 AI
2. 自己发送，再把 AI 返回的完整结果粘贴回「AI 整理结果」
3. 点击检查，逐条看差异和证据，确认后保存

软件会生成完整任务，不需要自己设计提示词或结果格式。修改受保护记忆需要额外勾选确认；来源或旧版本改变后必须重新审阅。结果不能通过检查时，修改结果后重试，不会直接写入错误内容。

## 记忆不准确或不想再使用

进入「记忆管理」，选择一条记忆，查看完整原文和出处。可以纠正内容、设置保护、遗忘，或勾选显示已隐藏内容后撤销自己的遗忘规则。

每次先预览再确认。遗忘会影响该记忆、来源记录和共用来源的其他记忆；预览会显示数量。文件会保留，撤销一条规则也不会自动撤销其他规则。修改正文不会把 AI 建议自动变成用户事实。

## 打开安装包

Arch Linux 优先使用 AppImage，Ubuntu 可安装 deb。便携 ZIP 解压后运行「运行桌面版.sh」，系统需要 Git、GTK 3 和 WebKitGTK 4.1。不要混用不同提交号的程序文件。

云端标准 Linux 原生验收与用户自己的 Arch/KDE Wayland 是不同环境。真实登录态网站与已安装扩展的兼容性，仍以实际连接结果为准；浏览器禁止安装时不修改安全策略。
