# 可选的会话原文组装

`search(target="events", detail="session_evidence")` 是独立验证中的简化路径。
它保留 discovery 的词法、向量两路会话顺序，以及已有 `limit` 和总 `budget_bytes`，
直接返回多个候选来源的有界上下文。排序权重、默认模式和候选规模不变；没有调用
reranker，也不把返回的来源标为答案。

## 先定位独立记录，再按需读取长文

每个来源保留检索已经找到的独立 Event，按来源首路、另一路逐条交替，按 Event
身份去重；各通道内部原排序不变。来源仍按 discovery 的现有顺序排列，不预选唯一
来源。记录数量由现有检索范围、分页和总字节预算控制，不把图锚点数量当成命中记录
数量上限。两个通道命中同一 Event 时只返回一份独立预览。

真实来源图仍由原先最多两个种子展开，每方向最多三跳，最多十二条图内消息。这些
种子只是图展开的工作量上限。同源其他独立命中仍会保留，且不借此声明它们互为邻居、
同一分支或连续对话。没有图时返回独立命中并保留 `source_graph_unavailable`，
不把保存顺序或时间先后补成边。

按 `limit` 将来源分批，每批先轮流分配各来源下一条独立命中的首片段；该批独立命中预览全部排完，
再以相同来源顺序轮流补未重复的真实图邻居。每条首片段最多 1024 UTF-8 字节，从语义命中范围
或词法命中位置截取。搜索不再自动把已有记录的长尾塞满剩余预算：需要完整原文时，
调用现有 `read`，传 `results.ref` 和所需 `offset_bytes`，并继续保留相同过滤条件。

`results` 中每段文字保持原文，附角色、时间、原引用、字节范围、snapshot 和引出
它的锚点。`sessions` 保留实际来源身份及各路排名、原始分数；`anchor_refs` 仅列
本页出现的独立命中，`graph_anchor_refs` 列有限图种子，`matching_anchor_count`
表示检索保留的独立记录数量。小页不重复列出该来源的全部引用。

各来源独立展开。某个来源图存在循环时保留该源独立命中，停止该源图展开并标注
`source_graph_cycle`；健康来源继续。旧 `session_context` 的循环错误语义保持不变。

证据够用时直接使用；不足时读取某条记录，或在候选 `session_ref` 内再次搜索。
会话标签不等于身份，仍须核对实际来源组。原有 reader 负责 scope、角色、时间、
`as_of`、分支和原始记录边界。

`next_cursor` 继续独立记录与图邻居的预览流，不自动读取长尾；查询、模式、limit
及字节预算必须一致。`status_scope=selected_evidence_previews` 和
`coverage.preview_only=true` 明确此范围。`complete` 仅表示预览流已读完，
不表示任何长记录或整场对话已完整读取。`text_truncated` 继续标记各原文缺口。

## 与旧入口的兼容边界

只有显式 `session_evidence` 使用新的预览顺序；旧 `session_context` 仍分页读取
其有界窗口的完整文字，其他 discovery 模式及默认搜索行为不变。新政策绑定游标，
旧政策产生的游标不能在新政策下继续。原始引用、范围、snapshot 和 read 工具保持
兼容，不新增判断证明、reranker、外部请求或调用者状态机。

## 成本与验证边界

预算包含整个返回 JSON，不只正文。丰富上下文可能减少首屏来源数；小预算仍可能
容不下所有独立命中，需要预览分页。原文覆盖、来源覆盖、总字节和调用次数应分别测量，不能把字节数
当作 token，也不能把更多文字直接称为答案质量提升。

本批测试仅使用原创合成原文和向量。已知问题的确定性回放也只能测覆盖与成本，不能
称为新盲测或泛化证据。生产默认保持原样，需独立检查与另行冻结的质量评估再决策。

## 收敛方向与可删除的旧假设

这个入口是暂时的对比边界，不是永久增加第七套调用流程。若独立检查和质量评估支持
组装路径，后续普通调用者收敛为一次搜索取得证据、必要时读取。届时修改主要工具
说明，停止扩展实验性判断证明控制器；旧模式名在明确的兼容期内作为适配入口保留，
允许迁移后删除各自的重复编排。

应淘汰的假设包括：最佳检索碎片代表整场对话；必须先选唯一来源才能定位记录；每次
检索都必须经过核查判断器和末条证明；格式验证能证明语义相关。需要保留的是权限、
来源与分支身份、原文不变和总工作量/字节预算。

验收看是否保住有用命中及前后交流、来源覆盖、总成本、调用者步骤是否更易理解，
不以防御分支或测试数量当作检索质量。
