# RecallCard：把一段对话带到另一个 AI

第一次使用只需创建资料库。搜索和会话交接不需要账号或 API 密钥。

## 1. 打开并创建资料库

打开桌面程序，点「创建新资料库」，选择一个空文件夹。以后打开同一个文件夹即可继续使用。

Arch Linux 优先打开 AppImage；Ubuntu 可以安装 deb。便携 ZIP 解压后运行 `运行桌面版.sh`，需要系统已提供 Git、GTK 3 和 WebKitGTK 4.1。文件名中的短提交号用于区分版本，校验摘要见同包清单。

## 2. 保存第一段对话

已有对话导出文件：进入「添加资料」，选择对应来源，选择文件，检查角色、原文与写入位置，再确认导入。相同来源、相同内容重复导入会去重。

正在 DeepSeek 或 ChatGPT 网页聊天：正常安装浏览器扩展后，点击「读取当前可见会话」，检查消息和角色。尚未连接本机时也能直接导出 JSON 或 Markdown；JSON 可以在桌面导入。只有导出下载完成并不表示已经保存到资料库。

需要从扩展直接保存时，再到桌面「连接与状态」设置浏览器和扩展 ID，并明确勾选保存权限。回到扩展检查连接，核对显示的资料库，然后预览、确认保存。若浏览器提示组织策略禁止安装，先使用导出文件导入路径，不修改浏览器安全设置。

网页捕获只包含当前已加载的普通可见消息，可能缺少历史、附件或原始时间；预览会保留这一说明。不要把它当成整个账号的完整备份。

## 3. 换一个 AI 继续

打开「会话与接续」，选择刚保存的对话，确认能看到原话和角色。填写下一步想做什么，点击「准备交接内容」，检查后复制到目标 AI，自己点击发送。

不必先整理长期记忆。交接会包含已保存原话、来源与覆盖说明，长会话只带有界的最近消息。接收方能读取发送的内容，复制前请检查是否适合分享。

## 用到时再设置

- 希望本地 AI 客户端按需查资料：在「连接与状态」生成 MCP 配置，加入你选定客户端的设置，再让它检索一句已经保存的原话。生成配置本身不代表客户端已经连接
- 希望长期记忆更简洁：在「整理记忆」选择来源并审阅整理结果。未经审阅的回复不会自动成为长期记忆
- 要了解来源、支持平台与当前验收范围：[桌面版说明](desktop-v0.2.md)、[浏览器保存与导出](browser-conversations-v0.3.md)

## 遇到问题

- **看不到刚保存的对话**：确认桌面和扩展使用同一资料库、同一资料分类，再刷新会话列表
- **扩展未连接本机**：先导出 JSON；连接设置与扩展实际连接是两件事，以扩展检查结果为准
- **没有完整历史**：网页可能只加载部分消息。优先导入平台提供的历史导出文件，保留原始备份
- **复制失败**：应用会显示错误，不会声称复制成功；可在交接预览框全选并手动复制
- **界面有功能但还没有真实宿主验收**：开发版会明确列出范围。合成测试不能替代你所在浏览器与已登录网站的实际兼容性
